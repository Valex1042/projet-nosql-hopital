# Gestion hospitalière : MongoDB et Python

Projet de la matière « Du SQL au NoSQL » (ENSP Douala, SDIA-3).
Application en terminal pour gérer patients, médecins, consultations,
prescriptions et hospitalisations, avec agrégations, index et archivage.

- `code/` : programme Python et instructions détaillées (`code/README.md`)
- `exports/` : base exportée en JSON et CSV (réimportable avec `mongoimport`)
- `captures/` : captures d'écran des résultats

Technologies : Python 3, pymongo, MongoDB.
